# Overview

A Python cryptocurrency trading bot that combines classical technical indicators (MACD, RSI, Bollinger Bands, Stochastic Oscillator) with machine-learning models (Random Forests, Gradient Boosting, Neural Networks) through an ensemble method. It targets Binance for order placement and can optionally use Azure for scalable training and data management. Algorithm weights are adjusted from historical performance, and new algorithms can be plugged into the ensemble.
